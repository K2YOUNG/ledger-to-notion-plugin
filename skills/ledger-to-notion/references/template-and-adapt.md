# 템플릿 복제 / 기존 가계부에 맞추기

## 템플릿 복제 (Notion에 가계부가 없을 때)

템플릿 원본 링크 (공개, 복제 허용됨): https://erratic-hydrofoil-9eb.notion.site/416b22459831818180f6f9cdcca41f71
- 페이지 제목은 "가계부". 거래 행은 모두 비워진 상태이고 카테고리·월별 통계 행만 들어 있다.
- 복제는 사용자가 이 링크를 열어 우측 상단 **Duplicate**(영문 UI) / **복제**를 눌러 자기 워크스페이스에 만드는 방식이다. 공개 링크는 `notion-duplicate-page`로 복제할 수 없으니, 사용자에게 직접 누르도록 안내한다.

구성: 가계부(입력 DB) / 월별 통계 / 수입·지출 분류 / 수입 카테고리 / 지출 카테고리. 월별·카테고리 합계는 DB의 수식·롤업이 자동 계산한다.

1. 사용자에게 템플릿을 복제해 쓸지 먼저 묻는다.
2. 위 공개 링크를 사용자에게 안내해 직접 복제하게 한다. 복제된 뒤 사용자가 복제본 URL을 알려 주면(또는 `notion-search`로 "가계부"를 찾으면) 다음 단계로 간다. 같은 워크스페이스 안의 페이지라면 `notion-duplicate-page`(deferred, ToolSearch로 불러온다)로 복제할 수도 있다. 템플릿의 공유 설정은 소유자 확인 없이 바꾸지 않는다.
3. 복제 후 `notion-fetch`로 새 가계부 DB의 data source ID를 얻고, 분류·지출 카테고리·수입 카테고리·월별 통계 4개 DB의 행 URL을 `notion-query-data-sources`(rows)로 조회해 사용자별 ID 표를 개인 설정 폴더(`~/.claude/ledger-to-notion-personal/notion-ids.md`)에 새로 만든다. 다른 사람의 ID 표를 재사용하지 않는다.
4. 사용자에게 카테고리를 확인받는다(없는 카테고리 추가 요청 가능, 단 DB 구조를 바꾸는 일은 묻고 한다).

## 기존 가계부에 맞추기 (이미 있을 때) — 아직 실험하지 못한 부분

배포자 본인의 가계부에서만 검증했고, 다른 구조의 가계부는 시험해 보지 못했다. 그래서 처음에는 항상 사용자 확인을 거친다.

1. `notion-fetch`로 DB 스키마를 읽고 속성을 의미로 대응시킨다.
   - 제목 → 이름/내용 / 날짜 속성 → 거래일 / 숫자 속성 → 금액(지출·수입이 한 열인지 두 열인지 확인) / select·relation → 카테고리 / 텍스트 → 메모 / 결제수단 속성이 있으면 해당 값.
   - relation이면 값은 페이지 URL 배열, select면 옵션 이름이다. 수식·롤업은 읽기 전용이라 쓰지 않는다.
2. 대응표를 사용자에게 보여주고 승인받는다. 애매한 속성은 묻는다.
3. 최근 행 20~30개를 조회해 이름 스타일, 카테고리 사용 습관, 금액 부호 규칙(지출을 양수로 쓰는지)을 파악해 따른다.
4. 필수 속성이 DB에 없으면 만들지 말고 알린다.
5. 대응표가 확정되면 개인 설정 폴더에 저장해 다음부터 재사용한다.

## 새해

연도별 DB다. 해가 바뀌면 새 연도 가계부가 필요하다. 사용자에게 알리고, 템플릿을 다시 복제(또는 전년도 DB 복제)한 뒤 ID 표를 갱신한다. 12월 말~1월 초에 연도가 다른 날짜가 들어오면 이 문제일 가능성이 크다.
